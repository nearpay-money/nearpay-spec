# @nearpay-internal/spec

Internal NearPay contracts: service-to-service route tables, domain event subjects, envelopes,
streams and consumers, and the 1Click wire schemas shared by the rails adapter and the sandbox.
Generated OpenAPI per service (`openapi/internal/`) and AsyncAPI (`asyncapi/events.yaml`) ship with
the package. Depends on `@nearpay/spec` at the same version.
