# @nearpay/spec

Public NearPay contracts as zod 4 schemas: REST route tables and objects, webhook events and the
`NearPay-Signature` header format, the NearPay x402 `exact` + `intents-transfer` scheme, NEAR Intents
payloads, and the error catalogue. Generated OpenAPI 3.1 (`openapi/public.yaml`), JSON Schemas
(`schemas/`) and shared test vectors (`test-vectors/`) ship with the package.
